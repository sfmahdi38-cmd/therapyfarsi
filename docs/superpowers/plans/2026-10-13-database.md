# Database (Plan 2 of N) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Supabase Postgres schema, row-level security and atomic SQL functions for booking, payment confirmation, cancellation, rescheduling, session outcomes, the doctor ledger, settlements, the job queue and webhooks — all tested locally without Docker.

**Architecture:** Plain SQL migrations in `supabase/migrations/` (the real Supabase format, applied unchanged to the cloud project in a later plan). Tests boot PGlite (Postgres 18 in WASM) with a small shim that mimics Supabase's `auth` schema and roles, apply every migration, and exercise functions as `anon`, `authenticated` (with JWT claims) or `service_role`. Rules that need judgement (attendance → session status) stay in `src/domain` (Plan 1); the database stores the result atomically and owns everything that must be race-free (overlap, money, ledger).

**Tech Stack:** PostgreSQL (Supabase), PGlite + `btree_gist`, Vitest, `@date-fns/tz` for test time helpers.

**Spec:** `docs/superpowers/specs/2026-10-13-tropifarsi-design.md` — sections 4-5, 4-7, 4-8, 6, 7 (all), 8-1, 9, 11, 12; section 16 overrides.

## Global Constraints

- Money: integer cents, currency `usd`. Toman stored as `bigint`.
- Overlap: `EXCLUDE USING gist (doctor_id WITH =, tstzrange(starts_at, blocked_until, '[)') WITH &&) WHERE (booking_status IN ('held','confirmed'))`.
- Ledger, settlements, allocations, policy versions and audit log are append-only (update/delete raise `immutable_table`).
- Every ledger row has a unique `source_key`; outcome rows use `booking:{id}:outcome:{n}`, late cancel uses `booking:{id}:late_cancel`.
- Every admin policy and admin function requires `auth.jwt()->>'aal' = 'aal2'`.
- `doctor_notes` has no admin policy. `payments` has no doctor policy.
- Views use `security_invoker = true`.
- Errors are raised as plain messages (`raise exception 'slot_taken'`) so the app can map them.
- Settings defaults: `min_lead_hours 12`, `max_horizon_days 30`, `hold_minutes 30`, `refund_window_hours 24`, `choice_window_days 7`, `free_reschedule_min_lead_hours 2`, `dispute_window_hours 24`.
- Weekly rules are Tehran wall-clock; Tehran has no DST. Grid: start on `rule.start + k × (session + buffer)`, session must end by `rule.end`.
- Mutation helpers (`app_*` that write) are not executable by `anon`/`authenticated`; service-only functions are executable by `service_role` only.
- Session outcome can only be recorded after `ends_at + 10 minutes` (spec 4-8 overlap window; reviewer note from Plan 1).

## Review Focus

1. A payment webhook for a hold that expired **by time but is still labelled `held`** while another client is trying to hold the same slot — expected: whoever commits first wins, the other gets `slot_taken` / `slot_lost`, never two confirmed bookings. → Task 3 test "late payment after another client took the slot".
2. A client reschedules into a slot that overlaps their **own** current booking (e.g. +1 hour shift) — expected: allowed, because the old booking is released in the same transaction. → Task 4 test.
3. Doctor share of **0** (bps 0) — expected: no zero-amount ledger rows (the `amount_cents <> 0` check must never fire from a function). → Task 5 test.
4. A client who is also flagged as a doctor (role `doctor`) calling `hold_slot` — expected: `clients_only`. → Task 3 test.
5. Admin signed in with only one factor (`aal1`) — expected: sees nothing and cannot call admin functions. → Task 2 and Task 5 tests.

-- Minimal stand-in for what Supabase provides before our migrations run.
do $$ begin
  if not exists (select 1 from pg_roles where rolname = 'anon') then create role anon nologin noinherit; end if;
  if not exists (select 1 from pg_roles where rolname = 'authenticated') then create role authenticated nologin noinherit; end if;
  if not exists (select 1 from pg_roles where rolname = 'service_role') then create role service_role nologin noinherit bypassrls; end if;
end $$;

create schema if not exists auth;
grant usage on schema auth to anon, authenticated, service_role;
create table auth.users (id uuid primary key, email text);

create function auth.jwt() returns jsonb language sql stable as
$$ select coalesce(nullif(current_setting('request.jwt.claims', true), ''), '{}')::jsonb $$;
create function auth.uid() returns uuid language sql stable as
$$ select nullif(auth.jwt()->>'sub', '')::uuid $$;
grant execute on function auth.jwt(), auth.uid() to anon, authenticated, service_role;

grant usage on schema public to anon, authenticated, service_role;
alter default privileges in schema public grant all on tables to anon, authenticated, service_role;
alter default privileges in schema public grant all on functions to anon, authenticated, service_role;
alter default privileges in schema public grant all on sequences to anon, authenticated, service_role;

import { PGlite, type Transaction } from '@electric-sql/pglite';
import { btree_gist } from '@electric-sql/pglite/contrib/btree_gist';
import { readFileSync, readdirSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { join } from 'node:path';
import { TZDate } from '@date-fns/tz';

const root = fileURLToPath(new URL('../..', import.meta.url));
const TEHRAN = 'Asia/Tehran';

export async function createDb(): Promise<PGlite> {
  const db = new PGlite({ extensions: { btree_gist } });
  await db.exec(readFileSync(join(root, 'tests/db/shim.sql'), 'utf8'));
  const dir = join(root, 'supabase/migrations');
  for (const f of readdirSync(dir).filter(f => f.endsWith('.sql')).sort()) {
    await db.exec(readFileSync(join(dir, f), 'utf8'));
  }
  return db;
}

export type Who = 'anon' | 'service' | { sub: string; aal?: 'aal1' | 'aal2' };

export async function as<T>(db: PGlite, who: Who, fn: (tx: Transaction) => Promise<T>): Promise<T> {
  return db.transaction(async tx => {
    if (who === 'anon') await tx.exec('set local role anon');
    else if (who === 'service') await tx.exec('set local role service_role');
    else {
      await tx.query(`select set_config('request.jwt.claims', $1, true)`, [
        JSON.stringify({ sub: who.sub, role: 'authenticated', aal: who.aal ?? 'aal1' }),
      ]);
      await tx.exec('set local role authenticated');
    }
    return fn(tx);
  });
}

/** Run one statement whose single result column is aliased `r`. */
export async function rpc<T = unknown>(db: PGlite, who: Who, sql: string, params: unknown[] = []): Promise<T> {
  return as(db, who, async tx => (await tx.query<{ r: T }>(sql, params)).rows[0]!.r);
}

let counter = 0;
export async function createUser(
  db: PGlite,
  opts: { role?: 'client' | 'doctor' | 'admin'; adult?: boolean; name?: string } = {},
): Promise<string> {
  const id = crypto.randomUUID();
  await db.query('insert into auth.users(id, email) values ($1, $2)', [id, `u${++counter}@test.local`]);
  if (opts.role && opts.role !== 'client') {
    await db.query('update user_roles set role = $2 where user_id = $1', [id, opts.role]);
  }
  await db.query('update profiles set full_name = $2, adult_confirmed_at = $3 where id = $1', [
    id, opts.name ?? 'Sara Test', opts.adult === false ? null : new Date(),
  ]);
  return id;
}

export async function createDoctor(
  db: PGlite,
  opts: { priceCents?: number; shareBps?: number; active?: boolean } = {},
): Promise<string> {
  const id = await createUser(db, { role: 'doctor', name: 'Ali Doctor' });
  await db.query(
    `insert into doctors(id, slug, gender, kind, price_cents, share_bps, is_active)
     values ($1, $2, 'male', 'psychologist', $3, $4, $5)`,
    [id, 'dr-' + id.slice(0, 8), opts.priceCents ?? 5000, opts.shareBps ?? 7000, opts.active ?? true],
  );
  for (let wd = 0; wd < 7; wd++) {
    await db.query(
      `insert into availability_rules(doctor_id, weekday, start_time, end_time) values ($1, $2, '08:00', '24:00')`,
      [id, wd],
    );
  }
  return id;
}

/** Tehran wall-clock time `daysAhead` days from today, returned as an absolute Date. */
export function tehranAt(daysAhead: number, hh: number, mm = 0): Date {
  const today = new TZDate(Date.now(), TEHRAN);
  return new Date(new TZDate(today.getFullYear(), today.getMonth(), today.getDate() + daysAhead, hh, mm, TEHRAN).getTime());
}

/** First hourly grid slot (Tehran 08:00–23:00) at or after now + hours. For 13 h this is always 13–22 h away. */
export function gridSlotAfter(hoursFromNow: number): Date {
  const z = new TZDate(Date.now() + hoursFromNow * 3_600_000, TEHRAN);
  const partial = z.getMinutes() > 0 || z.getSeconds() > 0 || z.getMilliseconds() > 0;
  let h = z.getHours() + (partial ? 1 : 0);
  let day = z.getDate();
  if (h >= 24) { h = 8; day += 1; } else if (h < 8) h = 8;
  return new Date(new TZDate(z.getFullYear(), z.getMonth(), day, h, 0, TEHRAN).getTime());
}

$$ select case when p_fixed is not null then p_fixed else round(p_price::numeric * p_bps / 10000)::int end $$;

$$ begin raise exception 'immutable_table'; end $$;

export async function holdAs(db: PGlite, client: string, doctor: string, startsAt: Date, ack = false): Promise<string> {
  return rpc<string>(db, { sub: client }, 'select hold_slot($1, $2, $3, $4) as r', [doctor, startsAt, 'Europe/London', ack]);
}

let eventCounter = 0;
export async function confirm(db: PGlite, bookingId: string, amountCents = 5000): Promise<string> {
  const n = ++eventCounter;
  return rpc<string>(db, 'service', 'select confirm_payment($1, $2, $3, $4, $5, $6) as r',
    [`evt_${n}`, bookingId, amountCents, 'usd', `cs_${n}`, `pi_${n}`]);
}

export async function bookAndPay(
  db: PGlite,
  opts: { clientId?: string; doctorId?: string; startsAt?: Date; ack?: boolean } = {},
): Promise<{ bookingId: string; clientId: string; doctorId: string; startsAt: Date }> {
  const doctorId = opts.doctorId ?? await createDoctor(db);
  const clientId = opts.clientId ?? await createUser(db);
  const startsAt = opts.startsAt ?? tehranAt(3, 21);
  const bookingId = await holdAs(db, clientId, doctorId, startsAt, opts.ack ?? false);
  const result = await confirm(db, bookingId);
  if (result !== 'confirmed') throw new Error(`bookAndPay: ${result}`);
  return { bookingId, clientId, doctorId, startsAt };
}

/** Simulate time passing: the session started `hoursAgo` hours ago (50 min session, 10 min buffer). */
export async function moveToPast(db: PGlite, bookingId: string, hoursAgo: number): Promise<void> {
  await db.query(
    `update bookings set starts_at = now() - make_interval(secs => $2 * 3600),
       ends_at = now() - make_interval(secs => $2 * 3600) + interval '50 min',
       blocked_until = now() - make_interval(secs => $2 * 3600) + interval '60 min'
     where id = $1`, [bookingId, hoursAgo]);
}

create function public.app_enqueue(p_type text, p_payload jsonb, p_key text, p_run_at timestamptz default now())
returns void language sql security definer set search_path = public as
$$ insert into jobs (type, payload, idempotency_key, run_at) values (p_type, p_payload, p_key, p_run_at)
   on conflict (idempotency_key) do nothing $$;

create function public.app_enqueue_reminders(p_booking uuid) returns void
language plpgsql security definer set search_path = public as $$
declare b bookings;
begin
  select * into b from bookings where id = p_booking;
  if b.starts_at - interval '24 hours' > now() then
    perform app_enqueue('reminder', jsonb_build_object('booking_id', b.id, 'kind', '24h'),
                        'reminder:24h:' || b.id, b.starts_at - interval '24 hours');
  end if;
  if b.starts_at - interval '1 hour' > now() then
    perform app_enqueue('reminder', jsonb_build_object('booking_id', b.id, 'kind', '1h'),
                        'reminder:1h:' || b.id, b.starts_at - interval '1 hour');
  end if;
end $$;

create function public.app_cancel_reminders(p_booking uuid) returns void
language sql security definer set search_path = public as
$$ update jobs set status = 'done', last_error = 'cancelled'
   where idempotency_key in ('reminder:24h:' || p_booking, 'reminder:1h:' || p_booking) and status = 'pending' $$;

-- Validates a start against lead/horizon, the doctor's grid and time off.
create function public.app_check_slot(p_doctor uuid, p_starts_at timestamptz, p_min_lead_hours int)
returns table (o_ends_at timestamptz, o_blocked_until timestamptz)
language plpgsql stable security definer set search_path = public as $$
declare
  d doctors;
  v_local timestamp := p_starts_at at time zone 'Asia/Tehran';
  v_min int := extract(hour from v_local)::int * 60 + extract(minute from v_local)::int;
begin
  select * into d from doctors where id = p_doctor and is_active;
  if not found then raise exception 'doctor_unavailable'; end if;
  if p_starts_at < now() + make_interval(hours => p_min_lead_hours) then raise exception 'too_soon'; end if;
  if p_starts_at > now() + make_interval(days => app_setting_int('max_horizon_days')) then raise exception 'too_far'; end if;
  if extract(second from v_local) <> 0 then raise exception 'not_on_schedule'; end if;
  if not exists (
    select 1 from availability_rules r
    where r.doctor_id = p_doctor
      and r.weekday = extract(dow from v_local)::int
      and v_min >= extract(epoch from r.start_time)::int / 60
      and v_min + d.session_minutes <= extract(epoch from r.end_time)::int / 60
      and (v_min - extract(epoch from r.start_time)::int / 60) % (d.session_minutes + d.buffer_minutes) = 0
  ) then
    raise exception 'not_on_schedule';
  end if;
  o_ends_at := p_starts_at + make_interval(mins => d.session_minutes);
  o_blocked_until := o_ends_at + make_interval(mins => d.buffer_minutes);
  if exists (
    select 1 from time_off t
    where t.doctor_id = p_doctor
      and tstzrange(t.starts_at, t.ends_at, '[)') && tstzrange(p_starts_at, o_blocked_until, '[)')
  ) then
    raise exception 'not_on_schedule';
  end if;
  return next;
end $$;

create function public.hold_slot(p_doctor uuid, p_starts_at timestamptz, p_client_timezone text,
                                 p_nonrefundable_ack boolean default false)
returns uuid language plpgsql security definer set search_path = public as $$
declare
  v_client uuid := auth.uid();
  v_slot record;
  d doctors;
  v_id uuid;
begin
  if v_client is null then raise exception 'not_authenticated'; end if;
  if coalesce((select role from user_roles where user_id = v_client), 'client') <> 'client' then
    raise exception 'clients_only';
  end if;
  if not exists (select 1 from profiles where id = v_client and adult_confirmed_at is not null) then
    raise exception 'adult_confirmation_required';
  end if;
  perform pg_advisory_xact_lock(hashtext(p_doctor::text));
  select * into v_slot from app_check_slot(p_doctor, p_starts_at, app_setting_int('min_lead_hours'));
  if p_starts_at < now() + make_interval(hours => app_setting_int('refund_window_hours'))
     and not coalesce(p_nonrefundable_ack, false) then
    raise exception 'nonrefundable_ack_required';
  end if;

  update bookings set booking_status = 'expired'
  where booking_status = 'held' and hold_expires_at < now() and (doctor_id = p_doctor or client_id = v_client);
  if exists (select 1 from bookings where client_id = v_client and booking_status = 'held') then
    raise exception 'hold_exists';
  end if;

  select * into d from doctors where id = p_doctor;
  begin
    insert into bookings (client_id, doctor_id, starts_at, ends_at, blocked_until, hold_expires_at,
                          policy_version_id, price_cents, doctor_share_cents, share_rule, client_timezone,
                          nonrefundable_ack_at, risk_flagged)
    values (v_client, p_doctor, p_starts_at, v_slot.o_ends_at, v_slot.o_blocked_until,
            now() + make_interval(mins => app_setting_int('hold_minutes')),
            (select id from policy_versions order by effective_from desc limit 1),
            d.price_cents, app_share_cents(d.price_cents, d.share_bps, d.share_fixed_cents),
            jsonb_build_object('share_bps', d.share_bps, 'share_fixed_cents', d.share_fixed_cents),
            p_client_timezone,
            case when p_nonrefundable_ack then now() end,
            coalesce((select risk_flag from intake_responses where client_id = v_client
                      order by created_at desc limit 1), false))
    returning id into v_id;
  exception when exclusion_violation then
    raise exception 'slot_taken';
  end;
  return v_id;
end $$;

create function public.confirm_payment(p_event_id text, p_booking uuid, p_amount_cents int, p_currency text,
                                       p_checkout_session_id text, p_payment_intent_id text)
returns text language plpgsql security definer set search_path = public as $$
declare
  b bookings;
  v_payment uuid;
  v_result text;
begin
  insert into stripe_events (event_id, type) values (p_event_id, 'checkout.session.completed')
  on conflict do nothing;
  if not found then return 'duplicate'; end if;

  select * into b from bookings where id = p_booking for update;
  if not found then
    perform app_enqueue('admin_alert', jsonb_build_object('kind', 'payment_unknown_booking', 'payment_intent', p_payment_intent_id),
                        'alert:unknown_booking:' || p_payment_intent_id);
    update stripe_events set processed_at = now() where event_id = p_event_id;
    return 'unknown_booking';
  end if;
  perform pg_advisory_xact_lock(hashtext(b.doctor_id::text));

  if exists (select 1 from payments where booking_id = b.id) then
    perform app_enqueue('admin_alert', jsonb_build_object('kind', 'duplicate_charge', 'booking_id', b.id, 'payment_intent', p_payment_intent_id),
                        'alert:duplicate_charge:' || p_payment_intent_id);
    update stripe_events set processed_at = now() where event_id = p_event_id;
    return 'duplicate_charge';
  end if;

  if p_amount_cents <> b.price_cents or lower(p_currency) <> 'usd' then
    v_result := 'mismatch';
  elsif b.booking_status in ('held', 'expired') then
    begin
      update bookings set booking_status = 'confirmed', hold_expires_at = null where id = b.id;
      v_result := 'confirmed';
    exception when exclusion_violation then
      v_result := 'slot_lost';
    end;
  else
    v_result := 'slot_lost';
  end if;

  insert into payments (booking_id, stripe_checkout_session_id, stripe_payment_intent_id, amount_cents, currency, status)
  values (b.id, p_checkout_session_id, p_payment_intent_id, p_amount_cents, lower(p_currency),
          (case when v_result = 'confirmed' then 'paid' else 'refund_pending' end)::payment_status)
  returning id into v_payment;

  if v_result = 'confirmed' then
    perform app_enqueue('email', jsonb_build_object('template', 'booking_confirmed', 'booking_id', b.id),
                        'email:booking_confirmed:' || b.id);
    perform app_enqueue_reminders(b.id);
  else
    perform app_enqueue('refund', jsonb_build_object('payment_id', v_payment, 'amount_cents', p_amount_cents, 'reason', v_result),
                        'refund:' || v_payment);
    perform app_enqueue('admin_alert', jsonb_build_object('kind', v_result, 'booking_id', b.id),
                        'alert:' || v_result || ':' || v_payment);
  end if;
  update stripe_events set processed_at = now() where event_id = p_event_id;
  return v_result;
end $$;

  p payments;

begin

  b bookings;
  v_uid uuid := auth.uid();
  v_actor text;
  v_refund text;

  end if;

  end if;

                      cancelled_at = now(), cancel_reason = p_reason, choice_deadline = v_deadline

    perform app_request_refund(b.id);

begin

-- Brings the booking's outcome rows (source_key booking:{id}:outcome:n) in line with its session status.
create function public.app_sync_outcome_earning(p_booking uuid, p_actor uuid) returns void
language plpgsql security definer set search_path = public as $$
declare
  b bookings;
  v_target int;
  v_current int;
  v_n int;
  v_delta int;
begin
  select * into b from bookings where id = p_booking;
  if b.session_status = 'needs_review' then return; end if;
  v_target := case when b.session_status in ('completed', 'no_show_client') then b.doctor_share_cents else 0 end;
  select coalesce(sum(amount_cents), 0), count(*) into v_current, v_n
  from doctor_ledger_entries where source_key like 'booking:' || b.id || ':outcome:%';
  v_delta := v_target - v_current;
  if v_delta = 0 then return; end if;
  insert into doctor_ledger_entries (doctor_id, booking_id, type, amount_cents, source_key, created_by)
  values (b.doctor_id, b.id,
          (case when v_delta < 0 then 'reversal'
                when b.session_status = 'no_show_client' then 'no_show_earning'
                else 'session_earning' end)::ledger_type,
          v_delta, 'booking:' || b.id || ':outcome:' || (v_n + 1), p_actor);
end $$;

create function public.claim_jobs(p_limit int) returns setof public.jobs
language sql security definer set search_path = public as $$
  update jobs set status = 'running', locked_at = now(), attempts = attempts + 1
  where id in (
    select id from jobs
    where (status = 'pending' and run_at <= now())
       or (status = 'running' and locked_at < now() - interval '5 minutes')
    order by run_at
    limit p_limit
    for update skip locked
  )
  returning *
$$;

create function public.complete_job(p_id uuid) returns void
language sql security definer set search_path = public as
$$ update jobs set status = 'done', locked_at = null where id = p_id $$;

create function public.fail_job(p_id uuid, p_error text) returns text
language plpgsql security definer set search_path = public as $$
declare j jobs;
begin
  select * into j from jobs where id = p_id for update;
  if not found then raise exception 'not_found'; end if;
  if j.attempts >= j.max_attempts then
    update jobs set status = 'failed', locked_at = null, last_error = p_error where id = p_id;
    return 'failed';
  end if;
  update jobs set status = 'pending', locked_at = null, last_error = p_error,
                  run_at = now() + make_interval(mins => power(2, j.attempts)::int)
  where id = p_id;
  return 'retry';
end $$;

create function public.record_refund_result(p_stripe_refund_id text, p_payment_intent text, p_amount_cents int, p_status text)
returns void language plpgsql security definer set search_path = public as $$
declare
  p payments;
  v_refunded int;
begin
  select * into p from payments where stripe_payment_intent_id = p_payment_intent for update;
  if not found then raise exception 'unknown_payment'; end if;
  insert into refunds (payment_id, stripe_refund_id, amount_cents, status)
  values (p.id, p_stripe_refund_id, p_amount_cents, p_status)
  on conflict (stripe_refund_id) do update set status = excluded.status;
  select coalesce(sum(amount_cents), 0) into v_refunded from refunds where payment_id = p.id and status = 'succeeded';
  update payments set refunded_cents = v_refunded,
    status = (case
      when p.status = 'disputed' then 'disputed'
      when v_refunded >= p.amount_cents then 'refunded_full'
      when exists (select 1 from refunds where payment_id = p.id and status in ('failed', 'pending')) then 'refund_pending'
      when v_refunded > 0 then 'refunded_partial'
      else p.status::text end)::payment_status
  where id = p.id;
  if p_status = 'failed' then
    perform app_enqueue('admin_alert', jsonb_build_object('kind', 'refund_failed', 'payment_id', p.id),
                        'alert:refund_failed:' || p_stripe_refund_id);
  end if;
end $$;

  if v_id is null then raise exception 'unknown_payment'; end if;
  perform app_enqueue('admin_alert', jsonb_build_object('kind', 'payment_disputed', 'payment_id', v_id),
                      'alert:payment_disputed:' || p_payment_intent);
end $$;

create function public.set_payment_fee(p_payment_intent text, p_fee_cents int, p_fee_currency text) returns void
language sql security definer set search_path = public as
$$ update payments set fee_cents = p_fee_cents, fee_currency = lower(p_fee_currency) where stripe_payment_intent_id = p_payment_intent $$;

          case when tg_op in ('UPDATE', 'DELETE') then to_jsonb(old) end,
          case when tg_op in ('INSERT', 'UPDATE') then to_jsonb(new) end);
  return null;
end $$;
